## 二、需求 → 设计映射（逐条）

1. **用户积分可直接使用模型广场中的模型** —— 口径确认为**纯按量**（不设采购/授权门槛）：任何已上架模型，只要积分余额够就能调；调用结束按 tokens 扣积分。因此**不建 `model_entitlements` 表**。
2. **管理员设置模型与价格（官方原价 + 平台折扣）** —— `model_catalog` 存**上游官方人民币价**（含缓存读写、最低收费、分档、附加组件），平台只加一个折扣率；积分价一律由 `points_settings.rate` 换算，**不提供按模型的积分覆写**。用户侧展示官方原价、折后价与醒目折扣标识。
3. **平台生成的 API Key 可直接调用模型** —— 新增 OpenAI 兼容入站端点 `GET /v1/models`、`POST /v1/chat/completions`（含 SSE）、`POST /v1/embeddings`，鉴权复用同一把 `ek_`。
4. **默认已有 AIPDD 系列；系统设置里输入的 Key 即该系列基础 Key** —— 预置静态 AIPDD 清单（`upstreamId=0`），调用一律取 `resolvePlatformToken()`，用户无需另配。
5. **用户自己生成的 API Key 与平台统一** —— 沿用「开放集成 → API Key 管理」同一把 `ek_`，同时服务业务 OpenAPI、MCP 与模型调用，不引入第二套 Key。（`api_keys.scopes` 现有代码从未参与鉴权判定，故不新增形同虚设的 `MODEL` 值。）
6. **用户模型用量要记录** —— `model_usage_logs` 为广场唯一用量事实源；站内试用（`IN_APP`）与对外调用（`API`）写同一张表，同时同步一行 `usage_events`（code `model_plaza`）让既有 AI 用量页与积分账本口径不断裂。
7. **本系统渠道名定义为 `LocalAPI`，并列于 `AIPDD`** —— `model_catalog.provider` 取 `AIPDD` / `LocalAPI` / 自定义厂牌；`LocalAPI` 是管理员从任意 baseURL 拉进来、由本系统网关统一对外呈现的渠道名。
8. **baseURL 默认被发现并可拉出对应模型** —— 管理端维护 `model_upstreams`（baseURL + Key），复用 `ContentModelCatalogService.list()` 拉 `/models`，做**新增 / 已有 / 已下架**三桶差异预览，勾选批量入目录。
9. **模型不仅在系统内可用，系统外也能用** —— 站内：模型详情抽屉里的「在线试用」；站外：第 3 条的 OpenAI 兼容端点 + API 文档页给出 `baseURL`、Key、`curl` 示例。

## 三、数据模型（新增 3 张表，MySQL 源）

```
model_upstreams         平台级上游渠道（管理员维护；AIPDD 内置不入库，用 upstreamId=0 表示）
  id, name, provider(默认 LocalAPI), baseUrl, keyCipher(VarChar(1024)，AES-256-GCM), protocol(openai|anthropic),
  enabled, remark, createdBy, createdAt, updatedAt
  unique(name)

model_catalog           平台可售模型目录（管理员维护）
  id, upstreamId(0=AIPDD 内置), provider, modelKey, upstreamModelKey(转发时真实模型名，空=同 modelKey),
  displayName, vendor, description,
  billingUnit(token|image|second|call),   // 与上游 aipdd.pricing.billing_unit 完全一致
  category(text|image|video|audio|embedding|other), // 能力分类：列表筛选与卡片标识，按 endpoints 推断
  quotaType(TOKEN|CALL),                  // 旧列保留：由 billingUnit 派生，仅供老代码读取
  inputRmbPrice  Decimal(18,6)    // 官方价：人民币 / 1M 输入 tokens
  outputRmbPrice Decimal(18,6)    // 官方价：人民币 / 1M 输出 tokens
  callRmbPrice   Decimal(18,6)    // 官方价：元 / 张、元 / 秒、元 / 次（按 billingUnit）
  cacheReadRmbPrice  Decimal(18,6) // 官方价：缓存读 / 1M tokens
  cacheWriteRmbPrice Decimal(18,6) // 官方价：缓存写 / 1M tokens
  minimumRmb     Decimal(18,6)    // 单次调用最低收费（如 ASR 0.01 元）
  tiers          Json?            // 上游分档：[{match:{quality|size|video_resolution},unitRmb}]
  components     Json?            // 上游附加组件：[{code,freeUnits,unit,unitRmb,tiers}]
  discountRate   Decimal(6,4)     // 平台折扣 (0,1]，1=不打折，只允许下调
  contextWindow Int, maxOutputTokens Int,
  modalities Json, endpoints Json, tags Json,
  enabled, sort, remark, createdBy, createdAt, updatedAt
  unique(provider, modelKey), index(upstreamId), index(enabled, sort)

model_usage_logs        用量流水（广场唯一事实源）
  id, userId, catalogId?, upstreamId, provider, modelKey,
  source(IN_APP|API), apiKeyId?, requestId, refId, endpoint,
  promptTokens, completionTokens, cacheReadTokens, cacheWriteTokens, totalTokens,
  billingQuantity Decimal(18,6), billingUnit,   // 媒体类计量：张数 / 秒数 / 次数
  pointsCost Decimal(18,4), rmbCost Decimal(18,6),
  elapsedMs, isStream, status(SUCCESS|FAILED), message, createdAt
  index(userId, createdAt), index(catalogId, createdAt), index(apiKeyId, createdAt)
```

迁移遵循仓库规范：MySQL 手写 `backend/prisma/migrations/0036_model_plaza/migration.sql`（JSON 列不给字面默认值、标识符 ≤64 字符），再 `node scripts/gen-prisma-schema.mjs` 派生 `schema.postgres.prisma`。

**精度口径**：人民币价用 `Decimal(18,6)`，积分扣减用 `Decimal(18,4)`（与 `PointsService` 账本精度一致）。单次调用积分 = `tokens / 1_000_000 × 每百万价`，四舍五入到 4 位；精确值 > 0 但舍入后为 0 时兜到 `0.0001`（最小账本单元），避免海量微调用完全免费。

## 七、计费与汇率口径（可核对）

- **汇率唯一来源**：`points_settings.rate` = 1 元人民币对应 N 积分（平台管理员在积分设置里调整，默认 10）。用户侧不可设置，目录里也不再保存任何积分覆写价。
- **计费单位与上游背靠背**：`billingUnit` 直接取上游 `aipdd.pricing.billing_unit`，不做平台自定义换算：
  | 能力 | 单位 | 官方价口径 | 计量字段 |
  | --- | --- | --- | --- |
  | 对话 / 向量 | `token` | 输入 / 输出 / 缓存读 / 缓存写，每百万 tokens | `promptTokens`、`completionTokens`、`cacheReadTokens`、`cacheWriteTokens` |
  | 图像生成 / 编辑 | `image` | 元 / 张，按 `quality`、`size` 分档；参考图超出量走附加组件 | `n`（张）、参考图数量 |
  | 视频 | `second` | 元 / 秒，按 `resolution` 分档 | 请求 `duration`（秒） |
  | 语音识别 | `second` | 元 / 秒，可设最低收费 | 上游 `duration`，缺失时按音频字节估算 |
  | 语音合成 | `call` | 元 / 次（上游即按次） | 1 |
- **官方价与折扣**：`official` 是上游官方价；`effective = official × discountRate`；`points = effective × rate`。用户侧卡片展示官方原价（划线）、折后价、积分价，并在醒目位置显示「平台折扣 X 折」。
- **调用成本**：
  - token：`(prompt×输入 + completion×输出 + cacheRead×缓存读 + cacheWrite×缓存写) / 1e6 × discount × rate`
  - 媒体：`数量 × 命中分档单价（未命中用基础单价）× discount × rate`，再套用最低收费；附加组件按 `max(0, 实际数量 − freeUnits)` 叠加。
  - 上游未回传 usage 时按字符数 / 音频字节估算，并在台账留痕。
- 扣减：`PointsService.debit(userId, 'SPEND', amount, { scene: 'model_plaza', refType: 'model', refId })`，余额不足抛 `POINTS_INSUFFICIENT`（对外端点转 OpenAI 风格 402 错误体），受既有 `spendDailyCap` 单日熔断约束。
- 限额：对外调用按 `api_keys.rateLimitDay` 逐 Key 日限额（统计当日 `model_usage_logs` 行数），并递增 `callCount`、刷新 `lastUsedAt`。
- 积分额度：`api_keys.points_quota` 逐 Key 累计消耗上限（汇总该 Key 的 `model_usage_logs.points_cost`，`source = API`），`NULL` = 不限额度；用完即拒（OpenAI 风格 402 `points_quota_exhausted`）。在「开放集成 → API Key 管理」按 Key 设置，可随时改为不限额度。

## 九、确认结论（2026-11-08）

| # | 议题 | 结论 |
| --- | --- | --- |
| 1 | 计价口径 | **与上游完全背靠背**：token（入/出/缓存读写，每百万）、image（按张，质量/尺寸分档）、second（视频按分辨率分档、ASR 带最低收费）、call（仅上游确实按次时，如 TTS）。人民币为官方原价，平台只加折扣率；积分统一按系统汇率换算，不允许按模型覆写。 |
| 2 | 采购模式 | **不需采购，纯按量**。取消 `model_entitlements`；上架即可调，余额不足则拒。 |
| 3 | 对外限额 | 复用 `api_keys.rateLimitDay`（默认 2000 次/日/Key），另可按 Key 设 `points_quota` 累计积分额度（超出即拒，可设不限额度），并受全站 `spendDailyCap` 积分熔断约束。 |
| 4 | Key 归属 | **统一平台 Key**（系统设置里那把 AIPDD Key）。不允许用户绑自己的 Key 覆盖广场调用。 |
| 5 | 并存关系 | 用户自带渠道模型**不进广场**，仍在「内容创作 → 模型设置」；广场只展示平台统一凭据的模型，价格口径单一。 |
| 6 | 初始目录 | **预置静态 AIPDD 清单**（迁移后 seed，默认 `enabled=true`，管理员可核价后随时下架或改价）+ 管理端「从 baseURL 拉取」实时刷新，做新增/已有/已下架三桶差异预览后勾选入库。 |

## 十、补充实现（2026-11-08）

- **调用方式**：目录卡片新增「调用方式」按钮，抽屉内按模型支持的 `endpoints` 切换，给出 cURL / Python / TypeScript / JavaScript 四套可直接运行的示例，并展示合并后的透传参数与速率限制说明；示例里的 baseURL 优先用管理员配置的站点域名，未配置时补当前访问域名。
- **本地直连**：`frontend/next.config.ts` 在非生产环境把同源 `/v1/*` 透传给后端，页面示例在本地开发也能直接跑通。
- **积分兑换码**：复用 `point_promo_codes` / `point_promo_redemptions`。**只有平台管理员能新建 / 编辑 / 删除兑换码**（后端 `requirePlatformAdmin`，前端按当前身份判定）；企业用户、个人、服务商只能输入兑换码点「兑换」入账，且列表接口对非管理员返回空数组，避免枚举。管理入口在「平台管理后台 → 积分与充值 → 兑换码」，积分中心同一页签对管理员也可见。
- **管理端概览**：`AdminMp_overview` / `AdminMp_listCatalog` 的 `aipdd.baseUrl` 统一返回实际生效地址（`GEO_LLM_BASE_URL` 或默认 AIPDD 地址），不再返回空串。
- **能力分类**：`model_catalog.category`（`text|image|video|audio|embedding|other`）按 `endpoints` 自动推断（`model-plaza.category.ts`），seed / 拉取 / 手工保存同口径；用户侧目录与管理端列表均支持按分类筛选，卡片带分类标签。
- **上架改为拉取式**：管理端「模型目录」不再手填模型——「上游通道」填好 baseURL 与 Key 保存后自动打开拉取弹窗并即时比对，按新增 / 已存在 / 已移除三桶展示（可按分类筛选），勾选后一键导入上架；如需微调价格再点编辑。种子内置清单仅作兜底（「补齐内置清单」）。
- **像素 / 分辨率分档**：图片按 `size`（如 `1024x1024`）或 `quality`（1K/2K/4K）、视频按 `video_resolution`（480p/768p/1080p/2k/4k）分档计价；管理端用「规格 + 单价」可视化行编辑（不再手写 JSON），用户卡片与调用说明展示像素/分辨率规格价（如 `1024×1024 ¥0.3 · 2048×2048 ¥0.4`、`480P ¥0.09 · 1080P ¥0.15`）。
- **折扣醒目展示**：卡片右上角固定折扣角标——有折扣时显示「X 折 · 省 N%」红橙角标，价格区同时给出划线官方原价与折后价；无折扣时价格区标注「官方价」，避免用户误判。分类改用胶囊页签（带数量）作为主筛选，搜索与渠道 / 厂商 / 计费 / 能力下拉收进同一行，并提供「重置筛选」。
